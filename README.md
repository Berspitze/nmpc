## Installation
Plugin requires 2 dependencies to work:
- Macos 
``` bash
brew install mpd mpc
``` 
- Debian
``` bash
sudo apt install mpd mpc
```
- Arch
``` bash
sudo pacman mpd mpc
```

### Lazy.nvim
```lua
{
    "Berspitze/nmpc",
    opts = {
        theme = {
            background = "None",
            foreground = "#E2E2E3",
            border     = "#44475A",
            title      = "#9ED072",
            selection  = "#3E445E",
            prompt     = "#9ED072",
        }
    }
}
```
